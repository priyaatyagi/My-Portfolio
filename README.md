# 1. Project Title

**Priya Tyagi – Personal Portfolio Website**

A clean personal portfolio website for Priya Tyagi, a BCA student and aspiring web developer. It shows her skills (HTML, CSS, JavaScript and MATLAB) and her projects: a Calculator and the Penguin Cafe website. It has a contact section and works on mobile, tablet and desktop.

# 2. Technologies Used

- HTML
- CSS
- JavaScript
- VS Code with Live Server extension

No frameworks are used.

# 3. Setup Instructions

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also just double-click `index.html` to open it in your browser. No installation is needed.
